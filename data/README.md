# Data

## Dataset

**NYC Capital Projects**

Source: NYC Open Data

This dataset contains information about major infrastructure and information technology capital projects reported by the City of New York.

The dataset includes information such as:

- Project name
- Project description
- Category
- Borough
- Managing agency
- Client agency
- Current project phase
- Design start date
- Budget forecast
- Budget changes
- Forecast completion
- Schedule changes

## Purpose

The dataset is used in this project to demonstrate:

- Data quality assessment
- Data cleaning
- Exploratory data analysis
- Statistical analysis
- Trend analysis
- Categorical analysis
- Budget analysis
- Schedule analysis
- Data visualization
- Business insight generation

## Data Source

NYC Open Data  
Dataset: Capital Projects  
Data Provider: Mayor's Office of Operations

## Data Usage

This project uses publicly available data for educational and portfolio purposes.

No confidential, proprietary or employer-owned data is included in this repository.

## Raw Data

The raw dataset is stored as:
